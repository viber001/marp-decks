# 页面原型

原型是起点。先判断这页承担什么，再选择最少但足够的视觉结构。

| 需要讲清什么 | 推荐轮廓 | 容易出的问题 |
| --- | --- | --- |
| 一个重要判断 | 黑 / 白大字页，一处强调 | 辅助说明太多，停顿消失 |
| 一项数据的意义 | 大数字、单位、口径、短结论；必要时配真实照片 | 数字抢眼但口径不可比较 |
| 一个新概念 | 一张关系图或具体场景，配短解释 | 蓝色发光球等装饰代替解释 |
| 阶段与递进 | 连续轨迹、节点、方向 | 三张独立卡片割断过程 |
| 三项并列能力 | 同一大容器、三个统一图标、共用基础条件 | 每项重复前提；容器套容器 |
| 两种状态 / 选择 | 对齐的对照或镜像视角 | 尺度不同，比较被视觉误导 |
| 一个真实案例 | 一张主图、必要标注、清楚结论 | 照片只是氛围，关键动作被裁掉 |
| 一个传播创意 | 话题主张与场景主图；机制 / 品牌承接两部分 | 热闹与品牌无关 |
| 预算或配置 | 清楚表格、合计、口径与必要注释 | 数字被装饰打断、费用重复计算 |
| 章节切换 / 演示 | 极简留白或一张满版图 | 为了变化临时增加无关内容 |

## 重点原型的几何判断

### 命题页

保留一个主要阅读入口。巨型标题与大面积留白形成力量；小前提或来源靠边，不能争夺主张。暗页蓝色渐变集中在真正重要的词上。

### 数据页

单位紧邻数字；时间、存量 / 流量、同比 / 累计等口径就近解释。多个数字并列不等于它们可以相加。来源用小而可读的文字保留，不能把引用页当作数据本身。

### 过程页

让位置、连线和颜色表达先后。节点数量服从内容；不预设“三步”。对探索阶段、未来阶段可用虚线或降低视觉权重，但要有文字解释。

### 成组能力页

图标用于辨认类别，尺寸与基线统一。先共享同一个大容器，再判断是否真需要分隔线。公共资源、前提或责任置于下方一次说明，各项专注差异。

### 真实图文页

图像通常占约 45%–65%，或按动作与主体决定。裁切前确认关键人物、产品、标识和现场关系。没有足够可信的照片时，可以用明确标注的示意或结构图，不伪装真实案例。

### 传播创意页

主标题能让人想象场景。主图呈现意外关系，正文解释“为何愿意讨论”和“品牌为何在场”。平台标识、热字、话题条可以传达传播语境；标清创意示意与传播目标，不制作虚假的成功证据。

### 对照与镜像页

对照对象共享画布、可见面积、标题基线与内边距。需要镜像时，用几何翻转外形和视角，文字与 UI 保持正向。样机中的内容必须落在设备开口内；无需依赖其他私有 Skill。

## 防止整套变成模板复制

连续相似页面出现时，先判断是否属于同一组需要可比的内容。需要可比时维持一致；需要推进叙事时，改变主图尺度、信息密度、底色或阅读方向。构图变化应有内容理由。
