# 成品 DNA

视觉克制，表达有判断。读者先看到一句值得记住的话，再看到支持它的结构与证据。

## 一套作品的稳定锚点

以下是起点；用户已有品牌规范或确认的页面优先。选定一套参数后全套复用。

| 项目 | 默认值 / 范围（1920×1080） |
| --- | --- |
| 画布 | 16:9，1920×1080 |
| 主文字 | 近黑 `#1D1D1F`；暗页用白 / 近白 |
| 底色 | 白 `#FFFFFF`、雾灰 `#F5F5F7`、近黑 `#050506` |
| 辅助文字 | `#86868B`；正文较长或背景偏灰时加深至 `#626268` |
| 强调色 | 蓝 `#0071E3`；允许少量青蓝到蓝紫渐变 |
| 中文字体 | PingFang SC → Noto Sans CJK SC / Noto Sans SC → Microsoft YaHei → sans-serif |
| 西文字体 | Helvetica Neue → Arial → sans-serif；用户环境有 SF Pro 时可选 |
| 安全边距 | 左右 96–128 px；上下 64–96 px |
| 巨型命题 | 84–132 px |
| 常规标题 | 56–80 px |
| 二级标题 | 34–48 px |
| 正文 | 24–32 px |
| 来源 / 注释 | 15–20 px |
| 大 / 小圆角 | 48–72 px / 20–36 px |

阴影轻、宽、低对比。强调色只突出本页真正要记住的词、关系或动作。避免整页泛蓝、连续发光、厚重浮雕和无意义的科技背景。

字号范围服务内容层级。信息过多时先合并重复、删除次要解释、换结构或拆页；缩字是最后一步。

## 用页面角色建立节奏

- **命题页**：低信息量、大字、强停顿；黑底或白底都可以。
- **解释页**：把概念转成关系、步骤或对比；读者能顺着图形复述。
- **证据页**：数据、截图或照片优先，结论紧贴证据。
- **场景页**：让人进入一个具体处境，理解抽象判断意味着什么。
- **收束页**：回到主张或下一步，不重复整套目录。

叙事从受众当前的认知出发，逐步建立新判断。按题目决定是否需要情绪、幽默或更大的命题，不能把某次个人演讲的哲学收尾套到所有客户提案。

总览里观察信息密度、底色、主图尺度与文字位置的变化。连续几页轮廓近似时，检查是否因为内容确实同类；若只是制作惯性，换一个更贴合内容的结构。无需机械规定黑页数量。

## 留白与构图

- 一个清楚的视觉重心通常比多个平均分配的小图更有力量。
- 可以左文右图、上命题下证据、单一物件居中、满版照片配边缘文字。
- 不对称由稳定边距与对齐托住。标题、正文、图片不必平均占据页面。
- 卡片适合独立并列项；流程和因果优先画出连接。
- 成组内容可以共用一个大容器，避免每层都套框。
- 对照、镜像、成组图标的尺寸与基线用同一数值生成，不依赖肉眼估算。

## 素材为什么出现在这里

为每个主要素材写一句用途，判断它承担哪种角色：

1. **证据**：真实截图、案例、表格、实物照片。
2. **语境**：人物、地点、产品使用环境。
3. **隐喻**：帮助理解观点的物件与动作，允许生成但标清示意。
4. **过程**：步骤、时间线、生命周期、系统关系。
5. **节奏**：让观众停顿、进入情绪或切换章节。

用户有真实场地、活动或产品素材时，优先采用。图标帮助观众迅速识别类别；不替代必要的解释。真实平台 Logo 或 App 图标用于平台识别，来源与使用方式应可追溯。

保持“原图来源”和“最终裁切”分开记录。主图清晰度不足时说明素材限制，不能用 4K 画布尺寸暗示照片也获得了新细节。
