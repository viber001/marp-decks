# 交付质检

按当前任务范围执行。单页检查相关项；整套同时检查叙事和最终导出。

## 内容与提炼

- [ ] 每页能用一句话复述主张，正文与素材确实支持它。
- [ ] 同页的两个模块互相支持；无关主张已拆开。
- [ ] 共同前提、基础资源和责任没有在各模块重复。
- [ ] 用户指定的原句、删改和数字进入了最终版本。
- [ ] 语气适合客户提案或个人演讲，没有强行幽默、攻击或哲学升华。
- [ ] 没有依赖空对仗、抽象动词和重复总结制造“有力感”。

## 证据与素材

- [ ] 事实、推断、拟议行动、未来愿景和生成示意可区分。
- [ ] 数据的单位、时间、口径和来源清楚；合计经过实际计算。
- [ ] 话题 / 榜单 / 新闻视觉没有伪装成已取得的传播成果。
- [ ] 主要素材承担证据、语境、隐喻、过程或节奏作用。
- [ ] 真实素材保留必要标识与上下文；裁切没有改变原意。
- [ ] 素材来源已记录；可分享包没有客户私密资料和个人账号路径。

## 视觉与节奏

- [ ] 字体、色板、边距、圆角和图标尺度属于同一套系统。
- [ ] 主标题一眼可读，正文与注释没有抢夺视觉重心。
- [ ] 内容密集页已先整理结构，再用图标和图形帮助阅读。
- [ ] 并列项和对照图共享必要尺寸、间距与基线。
- [ ] 页面轮廓的重复有比较需求；构图变化有内容理由。
- [ ] 总览中能看见信息密度与尺度的起伏，整套同时保持一致。
- [ ] 无文字溢出、缺字、异常断行、遮挡和误裁。

## 文件与导出

- [ ] 自动检查报告已查看，错误已修复；所有页面完成目检。
- [ ] 图片、图标和字体按预期加载，未依赖不可分享的个人路径。
- [ ] 页数、页序、页面标识正确，最后一页无额外空白页。
- [ ] PNG、总览、HTML 和 PDF 使用同一份已批准内容。
- [ ] 4K 单页 PNG 实际为 3840×2160；总览放大后可读。
- [ ] PDF 16:9，未带入按钮、导航条或浏览器页眉页脚。
- [ ] PDF 中渐变文字、深色页、透明层、阴影与图片没有新增瑕疵。
- [ ] 关键文字与图形尽量保留原生；局部栅格化清晰度足够，没有整页低清放大。
- [ ] 不将 HTML 或图片型文件称作原生可编辑 PPTX。

最终再问：这套作品是否让受众更容易理解并复述主张？若视觉很精致，但内容关系仍然费解，返回内容结构修正。
