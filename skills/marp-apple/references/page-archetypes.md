# 页面原型

原型是起点。先判断这页承担什么，再选最少但足够的结构。左列是「要讲清什么」，
中列直接给 Marp 里的写法。

## 对照表

| 需要讲清什么 | 推荐轮廓（Marp） | 常见问题 |
| --- | --- | --- |
| 一个重要判断 | `section.statement`：一句大字 + 一处强调 | 辅助说明太多，停顿消失 |
| 一项数据的意义 | 大数字 + 单位 + 口径 + 一句结论；必要时配真实照片 | 数字抢眼但口径不可比 |
| 一个新概念 | 一张关系图（SVG）或具体场景 + 短解释 | 用发光球、装饰几何代替解释 |
| 阶段与递进 | `.steps`：有序列表 + 竖线 + 节点说明 | 三张独立卡片，过程被切断 |
| 三项并列能力 | `.grid3` + 统一图标 + 底部共用条件 | 每项重复前提；容器套容器 |
| 两种状态 / 选择 | `.compare`：两列同宽同基线 | 尺度不同，比较被视觉误导 |
| 一个真实案例 | `section.figure`：主图 45%—65% + 标注 + 结论 | 图只是氛围，关键动作被裁掉 |
| 预算或配置 | `section.dense` + 表格 + 合计 + 口径 | 数字被装饰打断，合计算错 |
| 章节切换 | `section.lead` 或 `section.dark` | 为变化增加无关内容 |
| 收束 | `section.statement` 或 `section.lead`，落到下一步 | 重复全套目录 |

## 几何判断

### 命题页

只留一个阅读入口。大字与大面积留白形成力量；小前提、来源靠边，不争主张。
暗页的蓝色渐变只落在真正重要的词上，不超过一处。

### 数据页

单位紧邻数字；时间、存量/流量、同比/累计等口径就近解释。多个数字并列不等于可以相加。
来源用小而可读的字保留，不把引用页当数据本身。

### 过程页

位置、连线、颜色表达先后。节点数量服从内容，不预设「三步」。探索阶段与未来阶段
可用虚线或降权，但要有文字说明它尚未发生。

### 成组能力页

图标用于辨认类别，尺寸与基线统一。先共用一个容器，再判断是否真需要分隔线。
公共资源、前提、责任放在下方写一次，各项只写差异。

### 真实图文页

图像占 45%—65%，或按动作与主体决定。裁切前确认关键标识、人物、现场关系。
没有可信照片时，用明确标注的示意图或结构图，不伪装成真实案例。

### 对照与镜像页

两列共享可见面积、标题基线与内边距。需要镜像时翻转外形与视角，文字保持正向。
样机里的内容必须落在设备开口内。

## 哪种内容不该做成幻灯片

- 整页图片：文字不可检索、不可改、在投影上更糊。
- 大段表格：先拆成「一列能讲的指标」，其余进附录页。
- 目录页：除非听众需要按索引跳读，否则直接进第一条判断。

## 防止整套变成模板复制

连续相似页面出现时，先判断是否属于同一组需要可比的内容。需要可比就维持一致；
需要推进叙事就改主图尺度、信息密度、底色或阅读方向。构图变化要有内容理由。
