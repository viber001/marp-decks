# 交付质检

按当前任务范围执行：单页只查相关项，整套连同叙事与导出一起查。

## 内容与提炼

- [ ] 每页能用一句话复述主张，正文与素材确实支持它。
- [ ] 同页的两个模块互相支持；无关主张已拆开。
- [ ] 共同前提、资源、责任没有在各模块重复。
- [ ] 用户指定的原句、删改和数字进入了最终版本。
- [ ] 语气适合场景，没有强行幽默、攻击或哲学升华。
- [ ] 没有靠空对仗、抽象动词、重复总结制造「有力感」。

## 证据与素材

- [ ] 已发生、已有能力、拟议行动、未来愿景、示意图可区分。
- [ ] 数据的单位、时间、口径、来源清楚；合计确实算过。
- [ ] 主要素材承担证据、语境、隐喻、过程或节奏作用。
- [ ] 真实素材保留必要标识与上下文；裁切没有改变原意。
- [ ] 图片路径可分享；不依赖个人目录或本机绝对路径。

## 视觉与节奏

- [ ] 字体、色板、边距、圆角属于同一套系统。
- [ ] 主标题一眼可读，正文与注释不抢视觉重心。
- [ ] 密集页先整理了结构，再用表格或图形帮助阅读。
- [ ] 并列项与对照共用必要的尺寸、间距、基线。
- [ ] 页面轮廓的重复有比较需求；构图变化有内容理由。
- [ ] 整套看下来密度与尺度有起伏，同时保持一致。

## Marp 专属检查

- [ ] `slides.md` 是唯一源稿：同一内容没有第二份手改副本。
- [ ] 页面之间只有 `---` 分隔，没有多余空页或漏分隔导致两页合并。
- [ ] 页码：有封面（lead）时封面与封底不显示、正文从 1 起，网页与 PDF 相同；无封面时 1—N。
- [ ] 无溢出：`pixi run check` 无告警，或告警项已逐页目检确认。
- [ ] 代码块未横向溢出；长路径在 `--` 或 `/` 处可断。
- [ ] 中文与英文、数字之间空格一致；`pdftotext` 抽文中没有多余空格。
- [ ] 图片全部内联进 HTML，单文件可直接发给别人打开。
- [ ] PDF 与 HTML 来自同一次构建，页数与页序一致。
- [ ] 讲稿与页面一致：页数相同，每页注释的秒数与正文对得上。

## 文件与导出

- [ ] PDF 为 16:9，无空白页、无浏览器页眉页脚、无导航残留。
- [ ] 深色页、渐变、阴影、透明层在 PDF 中没有新增瑕疵。
- [ ] 交付目录只放成品；构建中间产物不写进同步盘或仓库。
- [ ] 不把 HTML、PDF 或图片型文件称作可编辑 PPTX。
