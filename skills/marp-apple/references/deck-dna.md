# 成品 DNA

视觉克制，表达有判断。读者先看到一句值得记住的话，再看到支持它的结构与证据。

以下是起点；用户已有品牌规范或确认过的页面优先。选定一套参数后整套复用。

## 稳定锚点（1280×720）

| 项目 | 默认值 |
| --- | --- |
| 画布 | 16:9，1280×720 |
| 主文字 | 近黑 `#1D1D1F`；暗页用 `#F5F5F7` |
| 底色 | 白 `#FFFFFF`、雾灰 `#F5F5F7`、近黑 `#050506` |
| 辅助文字 | `#86868B`；灰底或正文长时加深到 `#626268` |
| 强调色 | 蓝 `#0071E3`；最多一处渐变 |
| 中文字体 | PingFang SC → Noto Sans CJK SC → Microsoft YaHei |
| 西文字体 | Helvetica Neue → Arial |
| 安全边距 | 左右 56—64 px；上下 44—56 px |
| 巨型命题 | 56—88 px |
| 常规标题 | 40—48 px |
| 二级标题 | 28—34 px |
| 正文 | 20—25 px |
| 来源 / 注释 | 12—14 px |
| 圆角 | 大 24—32 px、小 8—12 px |

阴影轻、宽、低对比。强调色只标本页真正要记住的词、关系或动作；不做整页泛蓝、
连续发光、厚重浮雕。

信息过多时依次处理：合并重复 → 删次要解释 → 换结构（表、流程、对照）→ 拆页；
改字号是最后一步。

## 版式类名（`themes/apple.css`）

| 类名 | 用途 |
| --- | --- |
| `section.lead` | 封面、章节页、封底；大字、留白、无页眉 |
| `section.statement` | 命题页：一句话 + 极少辅助信息 |
| `section.dark` | 近黑底，白字；用于停顿、转折 |
| `section.figure` | 图文页：图占 45%—65% |
| `section.dense` | 证据页：表、代码、多行数据；正文降到 18—20 px |
| `.cols` / `.grid3` | 两栏 / 三栏并列 |
| `.steps` | 过程、阶段、时间线（用顺序列表 + 竖线） |
| `.compare` | 对照、镜像；两列共享基线与内边距 |
| `.takeaway` | 结论条，只用一次，放在证据之后 |
| `.source` | 来源、口径、注释 |
| `.tag` | 小标签：口径、状态、示意标注 |

## 用页面角色建立节奏

- **命题页**：低信息量、大字、强停顿。
- **解释页**：把概念转成关系、步骤或对照，读者能顺着结构复述。
- **证据页**：数据、截图或照片优先，结论紧贴证据。
- **场景页**：让人进入具体处境，理解抽象判断意味着什么。
- **收束页**：回到主张或下一步，不重复目录。

从受众当前认知出发，逐步建立新判断。是否需要情绪、幽默或更大的命题，
由题目决定，不把某次演讲的收尾方式套到所有材料上。

## 留白与构图

- 一个清楚的视觉重心，通常比多个平均分配的小图更有力。
- 左文右图、上命题下证据、单物件居中、满版图配边缘文字，都可以。
- 不对称由稳定边距与对齐托住；标题、正文、图不必平均分配页面。
- 卡片适合独立并列项；流程和因果优先画连接，而不是三张互不相干的卡片。
- 成组内容可以共用一个容器，避免每层都套框。
- 对照、镜像、成组图标的尺寸与基线用同一个数值，不靠肉眼估。

## 素材为什么出现在这里

为每张主要素材写一句用途，判断它承担哪种角色：

1. **证据**：真实截图、案例、表格、实物照片。
2. **语境**：人物、地点、使用环境。
3. **隐喻**：帮助理解观点的物件与动作；允许生成，但要标清示意。
4. **过程**：步骤、时间线、生命周期、系统关系。
5. **节奏**：让观众停顿、换气或进入下一节。

有真实素材时优先用真实素材。图标帮助辨认类别，不替代必要的解释。
示意图与真实证据要能一眼区分：示意图加 `.tag`，真实截图保留来源与裁切记录。
